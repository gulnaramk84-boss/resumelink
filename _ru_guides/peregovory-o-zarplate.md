## Сначала соберите данные

- Свежие вакансии с похожими задачами и указанной оплатой.
- Разговоры с людьми из отрасли.
- Официальная статистика вашей страны.

Не полагайтесь на одну цифру из интернета.

## Три суммы

1. Минимум, ниже которого не соглашаетесь.
2. Реалистичная цель.
3. Верхняя планка, которую можете объяснить.

## Фразы

```
Исходя из задач и моего опыта я ориентируюсь на диапазон [от] – [до]. Какой диапазон предусмотрен у вас?
```

```
Понимаю. Что можно обсудить кроме оклада: премию, обучение, график, срок пересмотра?
```

## Чего не делать

- Не называйте сумму ниже своего минимума из-за волнения.
- Не придумывайте другое предложение.
- Не соглашайтесь сразу: можно попросить день на раздумье.

## Получите письменно

Оклад, премии, испытательный срок, график и дату пересмотра.
